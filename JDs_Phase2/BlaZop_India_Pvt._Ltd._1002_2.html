PLACEMENT Full Stack Engineer – Angular & Web Technologies 400000 INR

Job Description

Role Overview We’re looking for Full Stack Engineers who can work across both frontend and backend aspects of modern web applications. The ideal candidates will primarily focus on developing highly responsive UI components using Angular 10+, while also contributing to API integration, data handling, and deployment workflows. This is a great opportunity to grow skills in building complete web applications in a real-world SaaS environment. Responsibilities • Design, develop, and maintain responsive and scalable frontend components using Angular 10+. • Translate UI/UX designs into functional interfaces with pixel-perfect precision. • Integrate APIs and ensure smooth data communication between frontend and backend. • Collaborate with design and engineering teams to develop full-stack features. • Ensure responsiveness, cross-browser compatibility, and performance optimization. • Build interactive visualizations using D3.js or similar JavaScript libraries. • Write clean, modular, and maintainable code. Skills Required • Strong knowledge of Angular 10+ and JavaScript/TypeScript. • Proficient in HTML5, CSS3/SCSS, and responsive web design. • Familiarity with consuming and integrating RESTful APIs. • Good understanding of Git and version control workflows. • Awareness of deployment practices and hosting static web apps is a plus. • Experience with data visualization libraries (e.g., D3.js, Chart.js) is a bonus.
