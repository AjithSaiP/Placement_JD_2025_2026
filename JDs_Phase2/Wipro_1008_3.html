Job Description

Role Overview We are seeking a Test Automation / Product Validation Engineer to work on automationdriven validation programs across two advanced domains: Automotive Instrument Cluster / Vehicle HMI Validation, and Enterprise Storage Systems Validation (Block / File / Object Storage), including AIenabled monitoring, analytics, and optimization features. The role focuses on the designing and execution of Pythonbased automated test solutions to ensure product quality, reliability, and performance. Key Responsibilities Test Automation & Execution (Common) Design, develop, and maintain Pythonbased automated test scripts and reusable utilities Execute and automate functional, regression, reliability, and systemlevel tests Ensure automation solutions are robust, repeatable, and reliable across builds and configurations Analyze test failures, perform debugging and rootcause analysis, and support defect triage Maintain test artifacts including test cases, automation scripts, execution reports, and documentation Continuously improve automation frameworks, testing processes, and quality metrics Required Skills & Qualifications Strong proficiency in Python programming for test automation and scripting Good understanding of software testing lifecycle (STLC), test case design, defect lifecycle, and validation practices Strong analytical thinking with excellent debugging and problemsolving skills Solid understanding of computer systems fundamentals (OS basics, memory concepts, processes, and file systems) Technical Skills (MustHave) Core Programming: Python Automation & Testing: Test automation concepts, STLC, regression testing, and reliability testing AI / Advanced Technologies: Python usage for AI / MLbased development and validation Why This Role Opportunity to work on cuttingedge validation programs spanning Automotive and Enterprise Storage domains Strong foundation in Pythondriven automation and product validation Exposure to AIenabled features and GenAI infusion within test engineering Career growth opportunities toward SDET, Senior Automation Engineer, or Validation Engineer roles
