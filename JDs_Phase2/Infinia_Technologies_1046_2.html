Job Description

About the Role Design, build, and operate the end-to-end data platform including ingestion, storage, transformation, and serving layers. Partner with product, engineering, and founders to translate business questions into data models and metrics. What You'll Do Design, build, and operate the end-to-end data platform — ingestion, storage, transformation, and serving layers Build reliable batch and streaming pipelines that move data from product, third-party APIs, and event streams into the warehouse and lakehouse Architect and operate a modern data lake / lakehouse on the Apache ecosystem — Apache Spark for distributed processing, Apache Iceberg / Hudi / Delta Lake for open table formats, Apache Parquet and Arrow for columnar storage and in-memory interchange, Apache Kafka for event streaming, and Apache Airflow for orchestration Model data for analytics and ML — clean, well-documented, versioned datasets that downstream teams can trust Partner with product, engineering, and founders to translate business questions into data models and metrics Take full ownership of data quality, freshness, lineage, and cost — not just "the pipeline ran" Proactively identify edge cases — schema drift, late-arriving data, duplicates, nulls, timezone bugs, PII leaks — before they corrupt downstream reports Set up monitoring, alerting, and data tests so issues are caught upstream, not by an exec staring at a broken dashboard Enable self-serve analytics — clean semantic layers, documented metrics, and dashboards people actually use Support AI/ML workflows — feature pipelines, embeddings, vector stores, retrieval pipelines What We're Looking For Strong product sense — can sit with the product team, understand the why behind a metric or data request, and push back when the question is wrong Ownership mindset — treats every dataset as yours; follows it from source system to dashboard and owns the trust people place in it Edge-case thinking — instinctively asks "what breaks this?" — schema changes, backfills, duplicates, late events, timezone confusion, PII — before the data reaches production Fluent in vibe coding — comfortable using AI tools (Claude Code, Cursor, Copilot) to write SQL, pipelines, and transformations quickly without losing rigor Strong Python fundamentals (pandas, pyarrow, typing, testing) Expert-level SQL — window functions, CTEs, query optimization, the works Hands-on with a modern warehouse — Snowflake / BigQuery / Redshift / Databricks Hands-on experience building on the Apache data ecosystem for modern data lakes — Apache Spark (batch and structured streaming), Apache Iceberg / Hudi / Delta Lake table formats, Apache Parquet / Arrow, Apache Kafka, Apache Airflow; familiarity with Apache Hive Metastore / catalog patterns and partition / compaction / time-travel semantics Experience with dbt for transformations and modeling Workflow orchestration with Airflow / Dagster / Prefect Comfortable on AWS / GCP (S3 / GCS, IAM, serverless basics) and object-store-backed lake architectures Solid grasp of data modeling — dimensional, normalized, event-based — and when to use which, including medallion (bronze / silver / gold) layouts on the lake Clear written communication; works well in async, low-meeting environments Nice to Have Django ORM / models experience for product-DB-aware pipelines Rust for performance-critical data tooling Deeper Apache ecosystem experience — Apache Flink for low-latency streaming, Apache Beam for unified batch / stream pipelines, Apache NiFi for dataflow, Apache Druid / Pinot for real-time OLAP, Apache Atlas for governance and lineage, Apache Superset for BI Streaming experience — Kafka, Kinesis, Flink, Spark Streaming Lakehouse formats — Iceberg, Delta Lake, Hudi — including catalog choices (Glue, Nessie, Polaris, Unity) Vector databases (pgvector, Pinecone, Weaviate) and RAG pipelines BI tooling — Looker, Metabase, Mode, Superset Data governance, lineage, and catalog tools (OpenMetadata, DataHub, Atlan, Apache Atlas) Prior startup or 0→1 experience — comfortable owning ambiguity end-to-end
